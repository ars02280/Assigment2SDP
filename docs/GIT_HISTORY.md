# Suggested meaningful Git history

The project was organized around the assignment stages:

1. Initial domain model and legacy direct creation
2. Add product abstractions
3. Introduce Factory Method
4. Add AMD, NVIDIA and Intel product families
5. Introduce Abstract Factory
6. Add runtime factory selection and business pipeline
7. Add automated tests and compatibility rules
8. Add Universal fourth family and final UML/report

Each stage corresponds to the required development story in the assignment. Avoid generic commit messages such as `update`, `fix`, `final`, `123` or `assignment2`.
